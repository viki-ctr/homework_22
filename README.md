# Skystore

## Описание:

Skystore - это отличный вариант хранения ваших плагинов и примеров кода, который вы бы хотели продать.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/viki-ctr/homework_22.git
```
2. Установите зависимости: mypy, flake8, black, isort, requests, django

## Применение:

1. Запустите модуль ``manage.py``.
2. В файле views прописаны котроллеры. 
3. В файле urls прописана маршрутизация.
4. Шаблоны размещены в файлах contacts, home.
